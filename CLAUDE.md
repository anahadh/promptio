# Promptio

Open-source Chrome extension. A fire button beside chat bars (Claude.ai, Gemini, ChatGPT) rewrites the prompt for a chosen mode (coding, idea generation, business plan). Jev (TypeSafe) scores prompt parts; Haiku 5.5 rewrites weak parts in parallel.

## Planning
- Plan lives in `docs/plan/`. Start with `00-index.md` and `decisions.md`, then open only the feature file you are working on.
- Work one feature at a time. Draft, get user review, then mark done.
- Keep feature files under ~150 lines. Put locked decisions in `decisions.md` (append-only, cite by D-ID).
- Ask the user only when genuinely unsure. Keep pace fast.
